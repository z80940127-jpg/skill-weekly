# Skill 周刊：自动化开源 Agent Skills 中文周刊设计

## 1. 目标与读者

`Skill 周刊` 是一个面向普通 AI 工具使用者的公开中文阅读网站。它每周自动收集近期热门、可追溯且具备实际用途的跨生态开源 Agent Skills，为用户和朋友提供可直接分享的简短阅读内容。

首版成功标准：

- 网站上线时即有真实的第一期内容可阅读和分享。
- 此后每周一北京时间早晨自动尝试发布新一期，当天发布即可接受。
- 每期提供至多 5 个新的正式精选项目；质量不足时宁可少发并说明原因。
- 读者不打开原始英文仓库，也能理解项目用途、适用对象与基础风险。
- 长期运行尽量使用免费能力，不引入管理后台、订阅系统或社交平台推送。

## 2. 内容产品设计

### 2.1 网站体验

网站采用清爽的周刊杂志式阅读体验：

- 首页突出最新一期，显示发布日期、当期简介和正式精选入口。
- 首页提供往期列表，每一期拥有独立、可分享的固定页面。
- 页面使用中文内容，保留英文项目名、原始开源仓库链接和来源说明。
- 网站公开展示自动生成说明、信息来源说明和“不构成安全背书”的提醒。

### 2.2 每期栏目

每期页面按照以下顺序展示：

1. **正式精选**：最多 5 个此前未推荐过、通过可信门槛的热门开源 Skill。
2. **持续热门**：此前推荐过、当期仍保持热度的项目；不占正式精选名额。
3. **风险观察**：具备讨论热度但可信信息不足的项目；不占正式精选名额，并显示明显风险标识。

若正式精选少于 5 个，页面明确写明本期未为凑数而降低筛选标准。首版自动流程中，已经进入过正式精选的项目不会再次占用正式名额；当期仍热门时仅进入“持续热门”。未来如需专题回顾或重新解读，由人工修正文案流程另行发布，不改变自动周更规则。

### 2.3 正式精选卡片

正式精选中的每个项目呈现：

- Skill 名称、来源仓库与原链接。
- 简明中文用途说明。
- 适合的用户或使用场景。
- 可识别的 Agent 工具兼容信息；项目未公开说明时标注“未说明”，不自行推断。
- 本周入选理由，包括近期热度或实用性信号。
- 基础风险提示与自动核验范围说明。

“风险观察”卡片不使用推荐措辞，必须清楚说明未进入正式精选的原因，例如许可证缺失、仓库说明不足或无法充分核验。

## 3. 筛选与发布规则

### 3.1 候选来源

- 以 `skills.sh` 的近期趋势榜单作为跨生态热门候选入口。
- 使用候选对应的 GitHub 原始仓库补充核验信息，包括仓库公开状态、许可证、项目说明、近期维护信息与可识别的风险信号。
- 不将 `skills.sh` 或自动摘要结果视为安全认证；站点只提供经过有限自动检查的内容筛选与阅读整理。

### 3.2 正式精选门槛

项目仅在同时满足以下条件时进入正式精选：

- 可定位到公开访问的原始开源仓库。
- 仓库包含可识别的开源许可证。
- 项目文档足以解释 Skill 的用途和基本使用场景。
- 项目此前未进入过正式精选。
- 基础自动风险检查没有发现明显危险指令、恶意行为或不适合向普通用户推荐的风险。

热度与实用性共同影响入选顺序：近期安装趋势或关注信号体现热度，文档可理解性和普通 AI 用户可使用价值体现实用性。

### 3.3 风险与失败处理

- 信息不足但具有关注价值的热门项目可以进入“风险观察”，并标出未通过正式门槛的原因。
- 检测到明确恶意行为或高度危险指令的项目完全不公开展示。
- 如果当周没有足够多的可信新项目，正式精选少于 5 项并如实说明。
- 如果候选来源解析失败、GitHub 核验无法完成、AI 中文内容生成失败或免费额度不足，则不发布新一期，保留最后一份成功发布的内容。

## 4. 技术与运营方案

### 4.1 技术形态

- 使用 `Astro` 构建轻量静态中文内容站。
- 每期周刊保存为仓库内的结构化内容文件，由静态构建生成首页、往期列表和单期页面。
- 使用公开 GitHub 仓库存放站点代码、生成流程与已发布周刊内容，保证历史内容可追溯。
- 使用 GitHub Actions 执行自动采集、核验、中文内容生成、内容提交和站点发布触发。
- 使用 GitHub Models 的免费调用能力生成短篇中文推荐文案；免费额度不足时按失败策略停止当期发布。
- 使用 EdgeOne Pages 连接 GitHub 仓库部署站点，首版使用平台分配的免费访问地址，不购买域名、不处理备案。

### 4.2 自动更新流程

1. 定时任务每周一北京时间约 08:00 启动；免费任务出现延迟时，当日成功上线即可。
2. 读取当期热门候选，并拉取对应公开仓库的核验资料。
3. 排除明确危险候选，将其余项目分为正式精选候选、持续热门候选和风险观察候选。
4. 为通过规则的条目生成中文阅读卡片与当期简介。
5. 验证一期内容符合栏目规则和必填信息后，将新一期文件提交至公开仓库。
6. EdgeOne Pages 随仓库更新重新构建并发布站点。

网站首次部署完成后，手动触发同一套自动流程生成第一期真实内容，使首个公开版本即可阅读。

### 4.3 人工修正

首版不建设登录后台。发布后若发现表述错误、风险变化或需要撤下项目，用户向 Codex 说明修正需求，由 Codex 协助修改对应周刊内容并触发重新部署。

## 5. 首版边界

首版包含：

- 最新一期首页、往期列表、独立期刊页。
- 正式精选、持续热门、风险观察三个栏目。
- 周一自动发布、首次手动触发首期生成。
- 基础筛选、风险处理、失败不发布与人工修正流程。

首版不包含：

- 邮件订阅、微信公众号或其他社交平台自动同步。
- 用户账户、收藏、评论或网页后台管理。
- 历史内容全文搜索、复杂分类过滤或个性化兴趣设置。
- 自有域名购买、域名备案或国内专属部署保障。

## 6. 验证标准

- 首次手动任务成功后，首页展示真实首期、正式精选卡片和可打开的原项目链接。
- 正常周更成功时，新期页面产生并成为首页最新一期，往期页面仍可访问。
- 重复热门项目不会占用新正式精选名额，而会显示在“持续热门”栏目。
- 信息不足的热门项目只显示在“风险观察”栏目，并带有明确说明。
- 明确危险项目不出现在公开内容中。
- 可用可信新项目少于 5 个时，页面少发且说明原因。
- 采集、核验或生成阶段失败时，不提交新一期且线上仍展示最后一期成功内容。
- 修正或撤下已发布条目后，站点重新构建并反映修改后的内容。

## 7. 已确定约束与默认值

- 站点名称为 `Skill 周刊`。
- 内容为中文，面向中国大陆为主的读者。
- 收录对象为跨生态开源 Agent Skills，而非资源导航网站。
- 内容调性为简洁易读的周刊，不是纯数据排行榜或个人博客。
- 正式精选强调近期热度与实际用途，安全与可追溯性优先于凑满数量。
- 站点公开、仓库公开，首版以免费能力和低维护成本为优先。
